# 子女養不起,國家養得起嗎?被隱藏的中低收入戶

2026「資料科學漫步」參賽作品的分析程式。使用華人家庭動態資料庫(PSFD)主樣本 2014–2024 年追蹤資料,檢驗社會救助法「子女收入算進長輩家庭收入」的假設;再模擬「子女只計實際給付」時,有多少沒有按月年金的長輩其實符合中低收入老人生活津貼(被隱藏的中低收入戶),以及國家要花多少錢接住他們。

**主要結果**(詳見 `report/`)

| 指標 | 結果 |
|---|---|
| 從子女拿到的錢達到最低生活費的長輩(2014–2024) | 每年只有 18%–23% |
| 沒有按月年金的長輩 | 約 203 萬人;不算子女時每人每月收入中位數 5,000 元,89% 低於最低生活費 |
| 子女只計實際給付時,符合津貼全額標準(低於 1.5 倍最低生活費) | 81%;問卷中領到中低收入戶生活補助者僅 2.4%(PSFD 沒有直接問老人生活津貼) |
| 依收入推算的「被隱藏的中低收入戶」(上限,未計資產與同住子女的支持) | 185 萬人(95% CI 171–197);保守版(排除有存款利息收入者)146 萬人(136–157);其中 74% 自評生活費夠用 |
| 第一階段:全數發給生活津貼(擇一) | 每年 837 億元(736–946);保守版 651 億元(559–739) |
| 第二階段:領完津貼後補足到最低生活費 | 再加 555 億元(476–642);保守版 428 億元(359–504) |

## 如何重現

1. 向中央研究院人文社會科學研究中心調查研究專題中心「學術調查研究資料庫」(SRDA)申請 PSFD 主樣本 RR2016、RR2018、RR2020、RR2022、RR2024,依 `data/README.md` 的結構放入 `data/`。
2. 安裝套件:`pip install -r requirements.txt`
3. 執行:`python run_all.py`(拔靴法 2,000 次;亂數種子固定為 2026,每次結果相同。測試時可用 `--boot 200`)
4. 閱讀說明:`jupyter notebook 分析說明.ipynb`(第 1–8 節用假資料,不需要真實資料也能執行)

## 分析步驟

| 步驟 | 內容 | 程式 | 對應報告 |
|---|---|---|---|
| STEP 1–3 | 讀入五波資料、各年題號對照、特殊碼處理、以受訪者編號串成長格式追蹤資料 | `data.py` | 2.1 |
| STEP 4 | 依經濟來源與退休歷史分為「月領年金」與「沒有月領年金」 | `data.py` | 2.1 |
| STEP 5 | 子女名冊:每個子女給的錢、工作狀態,加總回每位長輩 | `data.py` | 3.3 |
| STEP 5b | 檢驗「有子女就有人養」:2014–2024 年子女給的錢與當年最低生活費(2014 年為選用檔) | `data.py`、`analyses.py` | 3.1、圖 1 |
| STEP 6b | 同時控制健康、儲蓄、子女、居住安排、教育、地區的完整模型 | `analyses.py` | 3.2 |
| STEP 6–7 | 同一時間點比較:邏輯斯 / 線性迴歸,控制年齡、性別、年份,報告調整後比例;身體功能與慢性病逐項比較(Holm 多重比較校正) | `analyses.py` | 3.1、3.3、圖 1、圖 2 |
| STEP 8 | 兩波配對:遇到衝擊時快樂感的變化,「衝擊 × 有無年金」交互作用 | `analyses.py` | 3.4、圖 3 |
| STEP 9–10 | 夾心層與每月缺口(夫妻合計平分到每人,對照居住縣市當年最低生活費) | `estimate.py` | 3.2、表 1 |
| STEP 11 | 全台推估:年齡 × 性別事後加權;縣市內重抽鄉鎮市區的拔靴法信賴區間 | `estimate.py` | 2.3 |
| STEP 11b | 被隱藏的中低收入戶與兩階段成本試算、穩健性檢查(排除有存款收入、與子女同住者) | `estimate.py` | 2.2、3.3、3.4、表 1 |
| STEP 12 | 前提檢定與穩健性檢查(EPV、VIF、Hosmer–Lemeshow、Breusch–Pagan、順序邏輯斯迴歸、追蹤流失) | `analyses.py` | 3.5、研究限制 |

所有迴歸的標準誤皆依受訪者群聚校正(同一人出現在多年)。
